# Python Unit Testing Practice

A hands-on repository for learning and practicing **unit testing in Python**, with a focus on applications relevant to **data science and analytics**.

The goal of this repository is to build practical confidence writing reliable tests using `pytest`, progressing from basic Python functions to realistic data and machine learning workflows.

## Learning Objectives

Topics covered throughout the exercises include:

- Writing and running unit tests with `pytest`
- Assertions and expected outputs
- Edge cases and boundary testing
- Testing exceptions
- Testing numerical and floating-point results
- Testing Pandas and NumPy workflows
- Fixtures and test organization
- Testing data transformations and feature engineering
- Basic testing patterns for machine learning pipelines
- Basic mocking and dependency isolation
